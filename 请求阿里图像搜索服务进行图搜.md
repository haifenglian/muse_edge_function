## 需求-商品匹配

需要对supabase中的ai_match表进行图搜

1、根据ai_match表每一行数据，如果crop_image非空，则使用阿里云商品图片接口进行匹配
2、调用阿里云接口匹配时。根据category_id只对指定品类图库进行匹配
3、将匹配结果中置信度最高的一项，填写ai_match表的standard_product_id和置信度confidence


## 数据表(源)
```shell
create table public.ai_match (
  id uuid not null default gen_random_uuid (),
  source_table text not null,
  source_id text not null,
  standard_product_id text null,
  confidence double precision not null,
  crop_image text null,
  create_time timestamp with time zone null default now(),
  review_status text null default 'pending'::text,
  reviewed_at timestamp with time zone null,
  category_id text null,
  image_index integer null,
  source_name text null,
  constraint ai_match_pkey primary key (id),
  constraint ai_match_confidence_check check (
    (
      (confidence >= (0)::double precision)
      and (confidence <= (1)::double precision)
    )
  ),
  constraint ai_match_review_status_check check (
    (
      review_status = any (
        array[
          'pending'::text,
          'approved'::text,
          'rejected'::text
        ]
      )
    )
  ),
  constraint ai_match_source_table_check check (
    (
      source_table = any (
        array[
          'ods_social_media'::text,
          'ods_fans'::text,
          'ods_fashion_media'::text,
          'ods_ecommerce'::text,
          'ods_brand'::text
        ]
      )
    )
  )
) TABLESPACE pg_default;

create index IF not exists idx_ai_match_source on public.ai_match using btree (source_table, source_id) TABLESPACE pg_default;

create index IF not exists idx_ai_match_confidence on public.ai_match using btree (confidence) TABLESPACE pg_default;

create index IF not exists idx_ai_match_create_time on public.ai_match using btree (create_time) TABLESPACE pg_default;

create index IF not exists idx_ai_match_product on public.ai_match using btree (standard_product_id) TABLESPACE pg_default;

create unique INDEX IF not exists idx_ai_match_unique on public.ai_match using btree (source_table, source_id, standard_product_id) TABLESPACE pg_default;

create index IF not exists idx_ai_match_review_status on public.ai_match using btree (review_status) TABLESPACE pg_default;

create index IF not exists idx_ai_match_category_id on public.ai_match using btree (category_id) TABLESPACE pg_default;
```


## 阿里云图搜接口

请求地址：https://hasura-auth-worker.data-d1a.workers.dev/

```shell
额外请求头
{
  "Authorization": "Bearer xxxxxxxx"
}
```

graphql

```shell
mutation SearchImage($input: SearchImageInput!) {
  ali { searchImage(input: $input) {
    PicInfo {
      CategoryId
      Region
    }
    Auctions {
      CategoryId
      CustomContent
      IntAttr
      PicName
      ProductId
      Score
    }
    RequestId
    Success
  }
  }}
```
